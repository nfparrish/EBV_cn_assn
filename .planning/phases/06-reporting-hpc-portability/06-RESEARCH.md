# Phase 6: Reporting & HPC Portability - Research

**Researched:** 2026-02-26
**Domain:** Pipeline-native result bundling and publication-oriented summary generation
**Confidence:** HIGH

## Summary

A robust Phase 6 Wave 1 baseline should synthesize existing WGS association and RNA integration artifacts into a single reporting bundle generated by workflow execution, not manual post-processing.

Primary recommendation:
- Build a dedicated `REPORTING_BUNDLE` workflow that runs upstream workflows and emits standardized markdown/json/tsv report artifacts.

## Architecture patterns

1. **Source of truth = upstream outputs**
   - Use diagnostic JSON and top-hit TSV artifacts emitted by existing workflows.
2. **Deterministic summarization**
   - Produce stable ordering for merged top-hit tables.
3. **Portable report generation**
   - Keep report generation in a lightweight Python script with no heavy plotting dependencies for baseline wave.

## Pitfalls

- Missing upstream artifacts for report generation due workflow drift.
- Inconsistent p-value fields across layers.
- Overly strict assumptions on cohort size for significance summaries.

## Mitigations

- Require fixed input contracts from `assoc` and `rna` workflows.
- Use tolerant parsing with explicit `nan`/missing handling.
- Report availability/coverage flags explicitly in JSON summary.
